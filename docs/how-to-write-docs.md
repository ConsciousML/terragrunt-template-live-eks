# How to Write Docs

This repo defers to the catalog repo's [`docs/how-to-write-docs.md`](https://github.com/ConsciousML/terragrunt-template-catalog-eks/blob/main/docs/how-to-write-docs.md) for source-of-truth guidance and house style rules. Read it before writing or editing any doc here. It applies as written. This file only adds the doc type list for this repo.

## Doc Types in This Repo

- **Layer-index** (what a whole directory of things is): `README.md`
- **Operational guide** (procedural, task-oriented): `docs/ci_cd.md`, `docs/new_environment.md`, `docs/troubleshoot.md`, `docs/version_bump.md`
- **Config inventory** (file-by-file breakdown of what a directory of HCL resolves): `docs/configuration_files.md`
